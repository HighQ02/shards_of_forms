## 🚀 Быстрый старт

### Вариант 1: Использовать SimpleEnemy (рекомендуется для начала)

SimpleEnemy - это враги без спрайтов, отображаются как красные прямоугольники. Они работают из коробки!

EnemyManager уже настроен на использование SimpleEnemy:

```dart
final bool useSimpleEnemy = true; // в enemy_manager.dart (строка ~17)
```

**Готово!** Врагов можно запустить сразу.

### Вариант 2: Использовать Enemy с анимациями (требует спрайты)

Если у вас есть спрайты, отключите SimpleEnemy:

```dart
final bool useSimpleEnemy = false; // в enemy_manager.dart
```

Нужны спрайты в `assets/images/`:

- `enemy_idle.png` - 4 кадра (idle анимация)
- `enemy_walk.png` - 6 кадров (walking анимация)
- `enemy_death.png` - 5 кадров (death анимация)

## 🎮 Как это работает

### Спавн врагов

- Враги появляются каждые **10 секунд** (интервал варьируется от 5 до 15 сек)
- Спавнятся слева или справа экрана случайно
- Движутся горизонтально через весь экран
- Удаляются при выходе за границы

### Боевая система

#### Атака игрока

1. Нажимаем кнопку атаки
2. Создаётся хитбокс перед игроком (120px диапазон)
3. При попадании враг получает **20 урона**
4. Каждый враг получает урон только один раз за атаку

#### Враг получает урон

1. `enemy.takeDamage(20)` уменьшает HP врага
2. При HP ≤ 0 враг умирает
3. Игрок получает **10 опыта**
4. Враг исчезает через 0.5 сек после смерти

### Система опыта и уровней

#### Опыт

- За убийство врага: **10 XP**
- XP полоска показана в левой части экрана
- При заполнении полоски (достижении требуемого опыта) - уровень вверх

#### Повышение уровня

Все характеристики улучшаются на 15%:

- **max HP**: +20 (восстанавливается полностью)
- **Attack Damage**: +5 (урон атаки)
- **Move Speed**: +10 (скорость движения)
- **XP to Level Up**: ×1.15 (требуемый опыт увеличивается)

## ⚙️ Настройка

### Изменить интервал спавна врагов

В `lib/game/enemy_manager.dart` найдите:

```dart
double spawnInterval = 10;           // Текущий интервал (сек)
final double minSpawnInterval = 5;   // Минимум
final double maxSpawnInterval = 15;  // Максимум
```

Измените на нужные значения (в секундах).

### Изменить HP или урон врага

В `lib/game/simple_enemy.dart` (или `enemy.dart`):

```dart
double health = 30;      // HP врага
int xpReward = 10;       // Опыт за убийство
double moveSpeed = 100;  // Скорость движения
```

### Изменить урон атаки игрока

В `lib/game/player.dart`:

```dart
double attackDamage = 20;  // Урон атаки
```

### Изменить стартовое здоровье игрока

В `lib/game/player.dart`:

```dart
double health = 100;         // Текущее HP
double maxHealth = 100;      // Максимальное HP
```

## 🐛 Возможные проблемы

### Враги не появляются

- Проверьте, что `EnemyManager` добавлен в `MyGame.onLoad()`
- Убедитесь, что `gameWorld` не null

### Атаки не наносят урон

- Проверьте, что `AttackHitbox` добавляется в `gameWorld`
- Убедитесь, что враг имеет `RectangleHitbox()`

### HUD не отображается

- Проверьте, что `GameHUD` добавлен в `Stack` в `main.dart`
- Убедитесь, что `game` инициализирован

## 📈 Следующие шаги
