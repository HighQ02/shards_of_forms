# Система Врагов и Прогрессии

## Описание

В проект добавлена полнофункциональная система врагов, здоровья, урона и опыта для игры на Flame/Flutter.

## Компоненты

### 1. **Enemy** (`lib/game/enemy.dart`)

Класс врага с:

- **Здоровье (HP)**: 30 HP (настраивается)
- **Урон**: 5 единиц (настраивается)
- **Награда XP**: 10 опыта за убийство
- **Скорость движения**: 100 пикселей/сек
- **Анимации**: Idle, Walk, Death (требуют спрайты)
- **Поведение**:
  - Двигается слева направо или справа налево
  - Удаляется при выходе за границы экрана
  - При смерти запускается анимация death

### 2. **EnemyManager** (`lib/game/enemy_manager.dart`)

Менеджер врагов:

- **Спавн врагов**: Каждые 10 секунд (интервал случайный от 5 до 15 секунд)
- **Направление**: Случайный спавн слева или справа
- **Позиция спавна**: На уровне земли (worldHeight - 150)
- **Отслеживание**: Ведёт список всех врагов и удаляет погибших

### 3. **AttackHitbox** (`lib/game/attack_hitbox.dart`)

Хитбокс для атак игрока:

- **Диапазон атаки**: 120 пикселей перед игроком
- **Длительность**: 0.3 секунды
- **Урон**: attackDamage игрока (по умолчанию 20)
- **Механика**: Каждый враг получает урон только один раз за одну атаку

### 4. **GameHUD** (`lib/game/game_hud.dart`)

UI компонент для отображения:

- **HP Bar**: Текущее и максимальное здоровье с прогресс-баром (красный)
- **XP Bar**: Текущий и необходимый опыт с прогресс-баром (синий)
- **Уровень**: Текущий уровень персонажа
- **Счётчик врагов**: Количество врагов на экране

## Система игрока (Player обновления)

### Здоровье

```dart
double health = 100;         // Текущее здоровье
double maxHealth = 100;      // Максимальное здоровье

void takeDamage(double dmg)  // Получить урон
void heal(double amount)     // Исцеление
double getHealthPercent()    // % для полоски
```

### Опыт и Уровни

```dart
int level = 1;
double experience = 0;
double experienceToLevelUp = 100;
double attackDamage = 20;

void addExperience(double xp)      // Добавить опыт
void levelUp()                      // Повышение уровня
double getExperiencePercent()       // % для полоски
```

### Повышение уровня

При повышении уровня увеличиваются:

- **maxHealth**: +20
- **health**: Восстанавливается до максимума
- **attackDamage**: +5
- **moveSpeed**: +10
- **experienceToLevelUp**: ×1.15 (15% увеличение)

## Логика боевой системы

### Атака игрока

1. Игрок нажимает кнопку атаки
2. Создаётся `AttackHitbox` перед игроком (в сторону, куда он смотрит)
3. Хитбокс существует 0.3 секунды
4. При пересечении с врагом враг получает `player.attackDamage` урона
5. Каждый враг получает урон только один раз за одну атаку

### Враг получает урон

1. `enemy.takeDamage(damage)` уменьшает здоровье
2. Если здоровье ≤ 0, враг умирает
3. При смерти врага:
   - Запускается анимация death
   - Игрок получает `xpReward` опыта
   - Враг удаляется через 0.5 секунды

### Получение опыта

1. `player.addExperience(xp)` добавляет опыт
2. Если опыт >= требуемому для уровня вверх:
   - Опыт уменьшается на требуемый
   - Вызывается `levelUp()`
   - Проверяется возможность ещё одного уровня вверх

- Враги автоматически спавнятся
- Система коллизий обрабатывает удары

## Требуемые спрайты

Для врага нужны спрайты (в `assets/images/`):

- `enemy_idle.png` - 4 кадра
- `enemy_walk.png` - 6 кадров
- `enemy_death.png` - 5 кадров

Если спрайты не найдены, враги отображаются как простые прямоугольники.

## Возможные улучшения

1. **Враги наносят урон игроку**
   - Добавить столкновения враг-игрок
   - Враги должны наносить урон при касании

2. **Различные типы врагов**
   - Быстрые слабые враги
   - Медленные сильные враги
   - Враги с уникальными способностями

3. **Волны врагов**
   - Увеличение сложности
   - Сброс врагов между волнами

4. **Система звука**
   - Звук атаки
   - Звук смерти врага
   - Звук повышения уровня

5. **Предметы и дропы**
   - Враги дропят предметы
   - Лечебные зелья
   - Усилители урона

6. **Боссы**
   - Враги с больше HP и урона
   - Уникальные атаки
